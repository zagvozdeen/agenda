# Команды
- запустить базу данных: `docker compose up -d`
- запустить бэкенд: `go run cmd/main.go serve`
- собрать бэкенд: `make build`

# Соглашения
- используй Go 1.27, стандартный `uuid` и `encoding/json/v2`
- логику MCP пиши в `internal/api`, SQL — в `internal/store`
- комментарии в коде и тесты не пиши
- сообщения ошибок пиши на английском языке
- SQL пиши в строках с двойными кавычками; контекст, SQL и параметры переноси на отдельные строки
- схему из `schema.sql` не меняй; изменения БД оформляй отдельными миграциями после согласования
- соблюдай стиль соседних файлов, README.md меняй только по запросу
- работай в текущей ветке, новые ветки создавай только по запросу
- коммиты — Conventional Commits, короткий заголовок без описания и трейлеров; ключ задачи при наличии указывай в скобках в конце
- перед коммитом согласуй заголовок; без запроса не коммить и не деплой
