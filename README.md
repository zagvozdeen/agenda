# AGENDA

AGENDA (созвучно с agent) — минималистичный таск-трекер, которым пользуются не люди через интерфейс, а их ИИ-агенты
через MCP-сервер.

Минималистичный таск-трекер, которым пользуются не люди через интерфейс, а их ИИ-агенты через MCP-сервер. Задачи живут
на досках с трёхбуквенным ключом и получают сквозные номера вида ABC-12; у каждой есть описание, тип, приоритет, статус,
автор, исполнитель, оценка в часах и спринт. Агенты комментируют задачи, связывают их между собой и ищут по фильтрам
вроде «что Юля делала во втором спринте», а каждое изменение попадает в журнал. Смотреть любую доску может кто угодно, а
менять содержимое — только её участники с ролью owner или member. Пользователей и персональные API-токены заводит
администратор через консольные команды на сервере. Всё собрано в один Go-бинарник поверх PostgreSQL: он поднимает MCP,
публичную канбан-страницу только для чтения и админский CLI, поэтому деплой на VPS сводится к копированию одного файла.

1. `whoami` — кто я, на каких досках и с какой ролью.
2. `find_users` — найти человека по имени или логину.
3. `list_boards` — список досок.
4. `get_board` — доска, участники, активный спринт и число задач по статусам.
5. `create_board` — создать доску, автор становится owner.
6. `update_board` — изменить название или описание доски.
7. `delete_board` — мягко удалить доску.
8. `add_member` — добавить участника или сменить ему роль.
9. `remove_member` — убрать участника с доски.
10. `list_sprints` — спринты доски.
11. `create_sprint` — запланировать спринт.
12. `update_sprint` — изменить цель или даты спринта.
13. `start_sprint` — сделать спринт активным.
14. `close_sprint` — закрыть спринт и перенести незакрытые задачи.
15. `create_task` — создать задачу или подзадачу.
16. `get_task` — полная карточка задачи с подзадачами, связями, комментариями и событиями.
17. `update_task` — изменить любые поля задачи: статус, исполнителя, спринт и другие.
18. `delete_task` — мягко удалить задачу.
19. `search_tasks` — поиск задач по фильтрам и тексту с сортировкой.
20. `link_tasks` — связать две задачи.
21. `unlink_tasks` — удалить связь между задачами.
22. `add_comment` — добавить комментарий к задаче.
23. `update_comment` — изменить свой комментарий.
24. `delete_comment` — мягко удалить свой комментарий.
25. `list_activity` — лента изменений по доске, задаче или человеку.

---

1. `github.com/modelcontextprotocol/go-sdk` — официальный SDK для MCP-сервера.
2. `github.com/spf13/cobra` — CLI с подкомандами, справкой и автодополнением.
3. `github.com/jackc/pgx/v5` — драйвер и пул соединений PostgreSQL; SQL пишем вручную, строки в структуры раскладывает
   `pgx.CollectRows`.
4. `github.com/pressly/goose/v3` — миграции, вшитые в бинарник.
5. `github.com/BurntSushi/toml` — чтение конфига из TOML.
6. `github.com/google/uuid` — тип UUID в Go-коде.
7. `golang.org/x/time/rate` — ограничение частоты запросов к публичному API.
